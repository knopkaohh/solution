# PERSONAL 90

Персональная система развития на 90 дней: ежедневный план, сон, движение,
силовые тренировки, питание, Brain Lab, reviews и аналитика.

## Запуск

```bash
npm install
npm run dev
```

Приложение работает без backend. Все записи сохраняются в `localStorage`;
резервную копию можно скачать и восстановить в Settings.

## Проверки

```bash
npm run build
npm run lint
npm test
```

Browser-тест проходит полный сценарий Day 1 и проверяет сохранение данных
после перезагрузки, основные разделы, mobile-навигацию и export/import.
